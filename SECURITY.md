# Security

This plugin credits real payments, and its sweep tool signs with the plugin seed. Please report a security problem privately, not in a public issue.

- Use **Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting).
- Say what an attacker can do (for example: get an invoice marked paid without paying, redirect or double-count a payment, make the sweep tool send money elsewhere), what they need, and how to reproduce it.
- Test only against your own installation or testnet. Never against someone else's Bitcart host.

Ordinary bugs and improvements are welcome as normal issues and pull requests.
